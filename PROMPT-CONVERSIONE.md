# Prompt per convertire note in schede

Copia il testo qui sotto in Claude. Incolla le tue note alla fine.
Salva la risposta come file `.md` e importalo nell'app.

---

Converti le note che seguono in flashcards per lo studio.

Regole di formato (obbligatorie):
1. Prima riga: `# ` seguito dal nome dell'argomento.
2. Per ogni scheda con risposta lunga: una riga `## Domanda?` e sotto la risposta (massimo 5 righe, elenchi puntati se servono).
3. Per ogni scheda con risposta breve: una sola riga `Domanda :: Risposta` (con uno spazio prima e dopo `::`).
4. Una scheda = un solo concetto. Domande precise, non vaghe.
5. Usa solo informazioni presenti nelle note. Non aggiungere fatti nuovi.
6. Scrivi in italiano. Nessun testo prima o dopo le schede.
